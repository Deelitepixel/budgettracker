# Budget Tracker

A simple, lightweight, and responsive budget tracking application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Transaction Management**: Add income and expense transactions with description and amount (in Nigerian Naira ₦).
- **Edit & Delete**: Easily edit transactions or remove them with a confirmation prompt.
- **Search & Filter**: Search transactions in real-time by keyword, amount, or type.
- **Summary Dashboard**: View total balance, total income, and total expenses.
- **Persistent Storage**: Saves all data in the browser's `localStorage` so records stay after page refresh.
- **Responsive Design**: Clean and mobile-friendly UI.

## Getting Started

Simply open `index.html` in any modern web browser. No server, backend, or build step required.
